# A win hook so a page can celebrate

- **Pull request:** #44
- **Author:** Claude Code, working for Mike (@wilminator)
- **AI tool(s):** Claude Code (Sonnet 5.5)

## What and why

When the player walks out of the exit, `MazeHtml` showed one plain "YOU WIN!!!" box and played the `game_win` clip.
A page that wants more (fireworks, its own fanfare) had no way in. This adds one optional hook to `playGame`'s options,
in the same style as the hooks from #40:

- `onWin(info)`: called once, when the walk out of the exit has finished. `info` is `{state, moves, cells, actions, times, element}`;
  `element` is the jQuery-wrapped `#maze` the page can draw over. The page has the usual 10 seconds before the game clears away.
- If `onWin` answers `false`, the page says it did the banner and sound itself, and the view skips its plain box and `game_win` clip.
  Any other answer (including none) keeps them, so a page can add to the default instead of replacing it.
- No hook: nothing changes.

The hook is called after `setGameOver(true)` so the page sees the same state the plain box did.

## Look closely at

- The hook gets the live `#maze` element, so a hook that throws would stop the win from finishing. Pages should guard their own code.
- Replacing the default with `false` also drops the `game_win` clip; the page owns all win sound then (and must respect the sound settings, `playaudio` and `playvol` in `ui/music.js`).
