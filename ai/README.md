# AI notes

One note per pull request that used AI to write blocks of code, plan a change, or write tests.
See [Using AI tools](../CONTRIBUTING.md#using-ai-tools) for when a note is needed.

Name the file after the date and the change, for example `2026-10-21-plain-doors.md`, and copy
[TEMPLATE.md](TEMPLATE.md) to start. Notes are a record: once merged, they are not rewritten,
so a later change gets its own note.
